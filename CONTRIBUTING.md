# Contributing to linnotch

Thanks for wanting to help! linnotch is **open source, but it doesn't accept code contributions**. It's built and maintained by one team, [V25Group](https://www.v25group.com/), to keep it focused and consistent.

## What helps the most

- **Bug reports:** [open one here](https://github.com/v25group/linnotch/issues/new?template=bug_report.yml). Include your Windows version, the linnotch version (tray icon → first line), what you did, and what happened. A screenshot or short screen recording is gold.
- **Ideas and suggestions:** [suggest a feature](https://github.com/v25group/linnotch/issues/new?template=feature_request.yml). Explain the problem you want solved, not only the solution; it often leads somewhere better.
- **A 👍 on existing issues** tells us what matters to most people. Please don't open a duplicate.

## Pull requests

Pull requests are **closed automatically**, with a friendly note pointing here. If you've found a fix, describe it in an issue instead: what was wrong and how you'd change it. We'll build it ourselves and credit you in the changelog if you'd like.

## Forks

linnotch is under the [MIT License](LICENSE), so you're free to fork it and change your own copy. Please keep the copyright notice, and use a different name and icon for anything you publish, so people don't confuse it with the official linnotch.
