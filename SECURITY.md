# Security

If you find a security problem in linnotch, for example a way for a web page, another user or a program to make linnotch run code, read files or change settings, **please don't open a public issue**.

Report it privately instead: on GitHub, go to **[Security → Report a vulnerability](https://github.com/v25group/linnotch/security/advisories/new)**. Only the maintainers can see it there.

Please include what you found, how to reproduce it, and which version you used. We'll reply as soon as we can, fix it, and credit you in the release notes if you'd like.

## Supported versions

During the alpha, only the latest release gets fixes.

## What linnotch does on your PC

linnotch is designed to keep everything local; see the Privacy section of the [README](README.md#privacy). Its developer tools listen only on `127.0.0.1`, and only with a random token stored in your own user profile.
